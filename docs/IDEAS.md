## Идеи исследовательского вопроса

Как сделать вопрос «машинным», а не эконометрическим (лекция 1): цель — **предсказание** и сравнение моделей по ошибке на тесте (CV), а не причинный эффект. Похожая работа, которую обязательно упомянуть: **Folktables** (Ding et al., 2021, «Retiring Adult») — ML-задачи на ACS PUMS: доход > $50k, страховка, занятость, время в пути.

| # | Идея | Уровень, примерный n | Методы | Плюсы / риски | Статус |
|---|---|---|---|---|---|
| I1 | Кто работает из дома и как изменился «портрет» после COVID? Y = работал из дома (`JWTRNS` = 11) | работники, ~1.5 млн/год; из дома ~91 тыс. (2019) → ~243 тыс. (2022) | logit, LDA, KNN (подвыборка), lasso-logit по ~800 dummy профессий/отраслей, classification tree, CV; модель 2019 тестируем на 2022 | Сильный сдвиг между годами, сотни признаков → lasso к месту. Риск: тема популярная, в 2019 классы несбалансированы | ✅ D9 |
| I2 | STEM (переформулировка): насколько специальность диплома помогает **предсказать** зарплату и для кого «STEM-премия» больше? Y = log зарплаты | бакалавр+, 25–64, полная занятость, ~400 тыс. (2019), ~435 тыс. (2022) | linear regression с/без специальности (разница в test MSE), ridge/lasso по 173 специальностям + профессиям, splines для профиля «возраст–зарплата», regression trees для неоднородности | Сохраняет исходную идею. Риски: `SCIENGP` считает экономику и психологию наукой → своё определение STEM из `FOD1P`; не путать с причинным эффектом; отличаться от Folktables ACSIncome | 💡 Claude, 10.11 |
| I3 | Кто остаётся без медстраховки? Y = нет страховки (`HICOV` = 2) | 19–64 лет, ~1.9 млн/год, без страховки ~11% | logit, LDA, lasso, trees, выбор порога (ROC) | Понятная политика (штаты, Medicaid). Риски: похоже на Folktables ACSPublicCoverage; изменение между годами небольшое | 💡 Claude, 10.11 |
| I4 | Какие «типы» работников есть и как сдвинулись их доли 2019 → 2022? | работники 18–64 с зарплатой, ~1.3 млн/год (для кластеризации — подвыборка) | PCA → k-means / hierarchical clustering, описание кластеров | Задействует unsupervised часть курса. Риски: кластеры субъективны, сложно оценить качество. Лучше как дополнение к I1/I2 | ✅ D9 |
| I5 | Кто из 25–54-летних вне рабочей силы? Y = `ESR` = 6 | ~1.2 млн/год, ~18% | logit, LDA, lasso, trees | Важная тема. Риски: похоже на Folktables ACSEmployment, доля почти не изменилась | 💡 Claude, 10.11 |
| I6 | Контрфакт «2022 без COVID»: модель, обученная на 2019, предсказывает доход / занятость / бедность для людей 2022 «по правилам 2019»; разница с фактом = насколько изменилась экономика. Нормальный дрейф вычитаем бенчмарком 2016 → 2019 (тот же разрыв 3 года, без COVID). Признаки — только те, что COVID не меняет (возраст, пол, образование, раса, место рождения, штат); доходы в реальных ценах (CPI) | люди, ~1.3–1.9 млн/год | выбор лучшей модели по CV на 2019: linear regression, ridge/lasso, splines, trees, logit/LDA для занятости; trees для групп, где разрыв больше; + кластеры из I4 | Широкая экономическая тема, хорошо связана с лекцией 1 (prediction vs causal), если честно назвать допущения. Нужны данные 2016. Риски: разрыв = COVID + инфляция + господдержка + прочее, а не чистый COVID; пересечение с Folktables → отличаемся контрфактом | 💡 Aibek + Claude, 10.11 |
| I7 | Экономическое положение регионов: по каждому PUMA считаем безработицу, медианный доход, бедность, долю без страховки, образование, отрасли → PCA (индекс «экономического положения») + кластеры регионов; lasso/trees: что в структуре региона предсказывает безработицу и доход | ~2 350 PUMA (2019), ~2 460 (2022) | PCA, k-means / hierarchical, ridge/lasso, trees, CV | Ближе всего к «всей экономике». Риск: PUMA 2019 и 2022 с разными границами → сравнение лет через crosswalk или на уровне штатов | 💡 Claude, 10.11 |

## Что измеряем — предложение для I6 (💡 Claude, 10.11)

Взвешенные значения (`PWGTP`) посчитаны по ACS, деньги — в долларах 2022 (`ADJINC` + CPI).

| # | Показатель (Y) | Как считаем в ACS | Кто входит | Тип задачи | 2019 | 2022 |
|---|---|---|---|---|---|---|
| Y1 | Занятость | `ESR` ∈ {1,2,4,5} | 25–64 | классификация | 75.7% | 76.5% |
| Y2 | Безработица | `ESR` = 3 среди рабочей силы | 25–64 в рабочей силе | классификация (мало «да») | 3.7% | 3.5% |
| Y3 | Реальная зарплата | log(`WAGP` × `ADJINC` × CPI) | занятые 25–64, зарплата > 0 | регрессия | медиана ≈ $52 тыс. | ≈ $52 тыс. |
| Y4 | Часы работы в неделю | `WKHP` | занятые 25–64 | регрессия | 40.8 | 40.8 |
| Y5 | Бедность | `POVPIP` < 100 | 18–64 | классификация | 11.5% | 11.7% |
| Y6 | Нет медстраховки | `HICOV` = 2 | 19–64 | классификация | 13.3% | 11.6% |
| доп. | Работа из дома | `JWTRNS` = 11 | работавшие на прошлой неделе | классификация | 5.7% | 15.2% |
| доп. | Самозанятость | `COW` ∈ {6,7} | занятые 25–64 | классификация | 9.6% | 10.2% |
| доп. | Время на дорогу, мин | `JWMNP` | ездившие на работу | регрессия | 28.5 | 27.3 |

Признаки (X) — одни и те же для всех моделей и только те, что COVID не меняет: возраст, пол, образование (`SCHL`), раса (`RAC1P`), латиноамериканское происхождение (`HISP`), место рождения / гражданство (`NATIVITY`, `CIT`), семейное положение (`MAR`), штат (`ST`).

Нельзя измерить по ACS: инфляцию (нет цен), ВВП, потребление, богатство. Недели работы (`WKWN`) есть только с 2019, в 2016 — интервалами → для бенчмарка не годятся. Доход домохозяйства — только в файлах по жилью.
