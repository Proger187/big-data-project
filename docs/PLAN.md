## Цикл для каждого показателя (одинаковый у всех)

1. **2019:** взять людей из группы показателя; validation set: случайные 100 000 (train) и 50 000 (test) строк, seed 1.
2. На train подобрать параметры: λ (ridge/lasso) и размер дерева (pruning) — 5-fold CV; k (KNN) — на отложенной части train; KNN — на подвыборке 30 000 строк. Форма возраста — отдельно, `code/05_robustness_age_shape.R`.
3. Выбрать лучший метод, оценить его на test → `outputs/01_counterfactual/<y>/models_2019.csv`.
4. **2016:** то же самое → `outputs/01_counterfactual/<y>/models_2016.csv`.
5. **Бенчмарк:** лучшая модель 2016 предсказывает людей 2019 → `сдвиг_норм = взв.среднее(Y 2019) − взв.среднее(Ŷ)`.
6. **Контрфакт:** лучшая модель 2019 предсказывает людей 2022 → `сдвиг_covid = взв.среднее(Y 2022) − взв.среднее(Ŷ)`.
7. `избыточный = сдвиг_covid − сдвиг_норм` — в целом и по группам → `outputs/01_counterfactual/<y>/gaps.csv`.
8. **Где сдвиг больше:** остаток `Y − Ŷ` у людей 2022 → regression tree по X → `outputs/01_counterfactual/<y>/tree_residuals_2022.png`.
9. Записать итог в `docs/WORKLOG.md`, вклад ИИ — в `docs/AI_USAGE.md`, отметить `[x]` здесь, запушить.

Для классификации Ŷ — **вероятность**, а не 0/1. Средние — с весами `PWGTP`. Модели обучаем без весов.

В 2016 `SERIALNO` — число, с 2017 — строка (`2019HU…`). Храним как строку.

| Колонка | Кто входит (иначе NA) | Значение |

### Отбор признаков (лекция 7)

- **Кандидаты:** все признаки из таблицы X (кроме `region` и `race`) + взаимодействия: `educ × female`, `age × educ` + нелинейность по возрасту (`age²`; в сплайн-модели — `ns(age, 5)`).
- **Выбор:** lasso (для классификации — lasso-logit), λ по 5-fold CV; основная модель — `lambda.1se` (проще), для сравнения — `lambda.min`. В R: `glmnet::cv.glmnet`.
- **Сравнение:** ridge на тех же кандидатах; при желании — forward stepwise.
- **Результат для отчёта:** таблица «какие признаки lasso оставил для каждого Y» → `outputs/01_counterfactual/<y>/lasso_selected_<год>.csv`.
- Почему кандидаты именно такие (и почему нет профессии, часов и т.п.) — `docs/VARIABLES.md`.

### Готовые данные (`data/processed/acs_<год>.rds`)

Загрузка: `dt <- readRDS("data/processed/acs_2019.rds")` (это `data.table`).
Версия 11.11, 28 колонок. Люди 18–64, по году 1.9–2.0 млн строк. Колонки: `year, SERIALNO, SPORDER, PWGTP`, признаки X (таблица выше, включая 5 новых), `y1_employed … y5_poor`, а также `wage_real` (зарплата в $ 2022), `wfh`, `selfemp`, `commute_min` — для кластеров.
Для модели по конкретному Y берём строки, где этот Y не `NA`.

### Настройки расчётов

- seed: R `set.seed(1)`; validation set 100 000 / 50 000; 5-fold CV для λ и pruning; KNN — подвыборка 30 000.
- Метрики: регрессия — test MSE (+ R²); классификация — test error + AUC.
- Группы для разбивки сдвигов: возраст (18–24 только для Y5; 25–34, 35–44, 45–54, 55–64), `educ`, пол, `hispanic`, регион. Расу не используем (D15).
