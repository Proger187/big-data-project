## Цикл для каждого показателя (одинаковый у всех)

1. **2019:** взять людей из группы показателя; train/test 70/30 (seed — см. ниже).
2. На train сравнить свои методы (таблица ролей) через **5-fold CV**: подобрать λ (ridge/lasso), k (KNN), размер дерева (pruning), число узлов сплайна. KNN — на подвыборке 50 000 строк из train.
3. Выбрать лучший метод по CV, оценить его на test. Результат → `outputs/<y>_cv_2019.csv`.
4. **2016:** то же самое → `outputs/<y>_cv_2016.csv`. Метод можно оставить тот же, что лучший в 2019, — чтобы сравнение было честным.
5. **Бенчмарк:** лучшая модель 2016 предсказывает людей 2019 → `сдвиг_норм = взв.среднее(Y 2019) − взв.среднее(Ŷ)`.
6. **Контрфакт:** лучшая модель 2019 предсказывает людей 2022 → `сдвиг_covid = взв.среднее(Y 2022) − взв.среднее(Ŷ)`.
7. `избыточный = сдвиг_covid − сдвиг_норм` — в целом и по группам (см. ниже) → `outputs/<y>_gaps.csv`.
8. **Где сдвиг больше:** остаток `Y − Ŷ` у людей 2022 → regression tree по X → `outputs/<y>_tree_residuals.png` + короткое описание веток.
9. Записать итог в `docs/WORKLOG.md`, вклад ИИ — в `docs/AI_USAGE.md`, отметить `[x]` здесь, запушить.

Для классификации Ŷ — **вероятность**, а не 0/1. Средние — с весами `PWGTP`. Модели обучаем без весов.

## Общие правила (контракт данных) — у всех одинаково

### Колонки, которые читаем из сырых файлов

`SERIALNO, SPORDER, ST, PWGTP, ADJINC, AGEP, SEX, SCHL, RAC1P, HISP, NATIVITY, CIT, MAR, ESR, WAGP, WKHP, POVPIP` + для кластеров `JWTRNS` (в 2016 — `JWTR`), `COW`, `JWMNP`

В 2016 `SERIALNO` — число, с 2017 — строка (`2019HU…`). Храним как строку.

### Признаки X (для всех моделей одинаковые)

| Колонка в processed | Из чего | Правило |
|---|---|---|
| `age` | `AGEP` | число |
| `female` | `SEX` | 1, если `SEX` = 2 |
| `educ` | `SCHL` | 5 групп: `lt_hs` (1–15), `hs` (16–17), `some_college` (18–20), `ba` (21), `grad` (22–24) |
| `race` | `RAC1P` | `white` (1), `black` (2), `asian` (6), `other` (3, 4, 5, 7, 8, 9) |
| `hispanic` | `HISP` | 1, если `HISP` ≠ 1 |
| `foreign_born` | `NATIVITY` | 1, если `NATIVITY` = 2 |
| `citizen` | `CIT` | 1, если `CIT` ≠ 5 |
| `marital` | `MAR` | 5 категорий как есть (1 married … 5 never married) |
| `state` | `ST` | категория (51) |
| `region` | `ST` | 4 региона Census по штату (в файле 2016 нет `REGION`) — только для разбивки результатов, не в модели |

### Показатели Y

| Колонка | Кто входит (иначе NA) | Значение |
|---|---|---|
| `y1_employed` | 25–64 лет | 1, если `ESR` ∈ {1,2,4,5}, иначе 0 |
| `y2_unemployed` | 25–64 и `ESR` ∈ {1,2,3,4,5} | 1, если `ESR` = 3, иначе 0 |
| `y3_log_wage` | 25–64, `ESR` ∈ {1,2,4,5}, `WAGP` > 0 | log(`WAGP` × `ADJINC`/10⁶ × 292.655 / CPI года) |
| `y4_hours` | 25–64, `ESR` ∈ {1,2,4,5}, `WKHP` не пусто | `WKHP` |
| `y5_poor` | 18–64, `POVPIP` не пусто | 1, если `POVPIP` < 100, иначе 0 |

CPI-U (среднегодовой): 2016 = 240.007, 2019 = 255.657, 2022 = 292.655.

### Готовые данные (`data/processed/acs_<год>.rds`)

Загрузка: `dt <- readRDS("data/processed/acs_2019.rds")` (это `data.table`).
Люди 18–64, по году 1.9–2.0 млн строк. Колонки: `year, SERIALNO, SPORDER, PWGTP`, признаки X (таблица выше), `y1_employed … y5_poor`, а также `wage_real` (зарплата в $ 2022), `wfh`, `selfemp`, `commute_min` — для кластеров.
Для модели по конкретному Y берём строки, где этот Y не `NA`.

### Настройки расчётов

- seed: Python `42`, R `set.seed(1)`; train/test 70/30; 5-fold CV; KNN — подвыборка 50 000.
- Метрики: регрессия — test MSE (+ R²); классификация — test error + AUC.
- Группы для разбивки сдвигов: возраст (18–24 только для Y5; 25–34, 35–44, 45–54, 55–64), `educ`, `female`, `race`, `hispanic`, `region`.

### Выходные файлы (`outputs/`)

| Файл | Колонки |
|---|---|
| `<y>_cv_<год>.csv` | `method, tuning, cv_metric, test_metric` |
| `<y>_gaps.csv` | `group_var, group, actual_2019, actual_2022, pred_2019_from_2016, pred_2022_from_2019, gap_norm, gap_covid, gap_excess` (строка `group_var = all` — в целом по США) |
| `<y>_tree_residuals.png` | дерево по остаткам 2022 |

`<y>` = `y1`, `y2`, `y3`, `y4`, `y5`.
