- **Файлы:** `code/02_model_functions.R`, `code/03_run_models.R`, `code/03a/03b/03c_run_*.R`, `code/04_robustness_y5.R`, `outputs/y5_poor_robustness/`
- **Результат / вывод (Y5, бедность 18–64):**
  - Модели: лучший logit, AUC ≈ 0.77; lasso и ridge почти так же (регуляризация мало что даёт при 100 тыс. наблюдений и ~220 признаках); LDA ≈ 0.77; KNN 0.74–0.76 («проклятие размерности»); дерево 0.69–0.70. Средний прогноз ≈ средний факт → вероятности откалиброваны.
  - Lasso оставил ~40–65 из ~200–230 признаков: семейное положение, образование, дети, гражданство, штат.
  - Сдвиги: 2016→2019 факт ниже прогноза на 1.8 п.п. (нормальное улучшение); 2019→2022 факт ≈ прогнозу. **Избыточный сдвиг ≈ +1.7…+1.9 п.п.**: COVID-период остановил снижение бедности.
  - По образованию эффект тем больше, чем ниже образование (без школы ≈ +3.2…+3.6, магистр+ ≈ +0.5…+0.8) — устойчиво во всех вариантах. У латиноамериканцев больше, чем у остальных.
  - Устойчивость: без `children` результат почти не меняется (признак оставляем); без расы избыточный сдвиг 1.70 → 1.94, у латиноамериканцев 2.3 → 3.3 — раса искажала из-за смены кодировки → убрана (D15).
  - `outputs/y5_poor/` в репозиторий пока не кладём: это старая версия (с расой), нужно перезапустить `code/03c_run_y5_aibek.R`.
