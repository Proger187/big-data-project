# Переменные ACS: что берём, что можно взять, что убираем

> Статус: 🗣 Aibek выбрал из группы B: `YOEP`, `WAOB`, `SCIENGP`, `FOD1P`, `PAOC` (11.11) — они уже в `.rds`. Остальное из группы B не берём. Связано с D14 в `docs/IDEAS.md`.
> В файлах по людям ~130 содержательных колонок, плюс 80 репликационных весов и ~80 флагов импутации.
> Все переменные из групп A и B есть во всех трёх годах (2016, 2019, 2022). Коды проверять по Data Dictionary.

**Главный принцип отбора.** Для контрфакта «2022 по правилам 2019» в признаки X можно брать только то, что **COVID не мог изменить**: человек с этим родился или это сложилось до 2020. Всё, что пандемия сама сдвинула (работа, доход, переезды, учёба, состав семьи), — это либо наши Y, либо «плохие контроли»: они «съедят» разницу, которую мы хотим измерить.

## B. Можно взять — кандидаты для выбора через lasso (лекция 7)

Все «доковидные». Если берём, их нужно добавить в скрипт подготовки и пересобрать `.rds`.

| Колонка | Что это | Как кодировать | Комментарий |
|---|---|---|---|
| `ENG` | насколько хорошо говорит по-английски | 5 категорий; пусто = «говорит только по-английски» | сильный кандидат для занятости и зарплаты |
| `LANX` | говорит дома не на английском | 0/1 | вместе с `ENG` |
| `YOEP` | год въезда в США | лет в США = год опроса − `YOEP`; для рождённых в США — 0 + флаг | сильный кандидат: иммигранты |
| `WAOB` | регион мира рождения (8 групп) | категория | компактнее, чем `POBP` |
| `MIL` | служил ли в армии | ветеран / нет | сильный кандидат |
| `SCIENGP` | диплом в науке/инженерии (STEM по NSF) | 0/1; пусто = нет бакалавра | в STEM попадают и экономика с психологией |
| `FOD1P` | специальность бакалавра (~170 кодов) | категория; пусто = нет бакалавра | идеально для lasso: много dummy |
| `DIS` | есть инвалидность | 0/1 | ⚠ спорно: COVID мог повлиять (long COVID) |
| `DEAR`, `DEYE`, `DREM`, `DPHY`, `DDRS`, `DOUT` | виды инвалидности | 0/1 каждая | ⚠ то же; можно вместо `DIS` |
| `PAOC` | есть ли свои дети и какого возраста (только женщины) | категория; у мужчин — отдельная | ⚠ рождаемость чуть сдвинулась |
| `MARHT` | сколько раз был в браке | 1 / 2 / 3+ | слабый кандидат |
| `QTRBIR` | квартал рождения | категория | почти наверняка бесполезен — хороший пример, что lasso его выкинет |
| `POBP` | место рождения (штат или страна, ~200 кодов) | категория | очень подробно; лучше `WAOB` |
| `RAC2P`, `RACNUM` | подробная раса, число рас | категория | дублирует `RAC1P` |

Плюс **взаимодействия и нелинейность** из уже взятых X: возраст², сплайн по возрасту (лекция 10), образование × пол, образование × раса, возраст × образование. Тогда у lasso сотни кандидатов, и выбор становится содержательным.

## C. Убираем

### C1. Это наши результаты или их составные части (не X)

`OCCP`, `SOCP` (профессия), `INDP`, `NAICSP` (отрасль), `WKWN` / `WKW` (недели работы), `WKL` (когда последний раз работал), `WRK` (работал на прошлой неделе), `NWAB`, `NWAV`, `NWLA`, `NWLK`, `NWRE` (поиск работы, временное отсутствие), `PERNP` (заработок), `PINCP` (весь доход), `SEMP`, `INTP`, `SSP`, `SSIP`, `PAP`, `RETP`, `OIP` (виды доходов).

COVID сам их изменил: «плохие контроли».

### C2. Тоже изменил COVID (поведение и обстоятельства)

- `JWAP`, `JWDP`, `JWRIP`, `DRIVESP`, `POWPUMA`, `POWSP` — время выезда, попутчики, место работы.
- `MIG`, `MIGSP`, `MIGPUMA` — переезжал ли за год.
- `SCH`, `SCHG` — учится ли сейчас.
- `FER` — рожала ли за год.
- `MARHD`, `MARHM`, `MARHW`, `MARHYP` — браки и разводы за последний год.
- `RELSHIPP` (2016: `RELP`), `MSP` — положение в семье: в пандемию многие молодые переехали к родителям.
- `GCL`, `GCM`, `GCR` — уход за внуками.

### C3. Медстраховка (Y6 решили не брать)

`HICOV`, `HINS1`–`HINS7`, `PRIVCOV`, `PUBCOV`, `HIMRKS`.

### C4. Технические и дублирующие

- `RT` — всегда «P».
- `PWGTP1`–`PWGTP80` — репликационные веса для стандартных ошибок по методике Census; модели курса их не используют.
- Флаги импутации `F…P` (~80) — не признаки. Максимум для проверки устойчивости: например, убрать людей с `FWAGP` = 1 (зарплату за них досчитал Census).
- `PUMA` — между годами несравнимы; `REGION`, `DIVISION` — выводятся из `ST`.
- `DECADE`, `CITWP` — дублируют `YOEP`.
- `MLPA` … `MLPJ`, `MLPIK`, `VPS`, `DRAT`, `DRATX` — детали военной службы; хватит `MIL`.
- `ANC`, `ANC1P`, `ANC2P`, `RAC3P`, `RACAIAN`, `RACASN`, `RACBLK`, `RACNH`, `RACPI`, `RACSOR`, `RACWHT`, `LANP` — слишком подробные происхождение, раса и язык; дублируют A и B.
- `FOD2P`, `SCIENGRLP` — вторая специальность и «смежный с наукой» флаг.
- `ESP`, `OC`, `RC`, `NOP`, `SFN`, `SFR` — переменные про детей и подсемьи; для 18–64 не нужны.

## Как это связать с курсом

1. **Уровень 1 (группы A/B против C):** решаем логикой контрфакта и описываем в отчёте. Это осознанный отказ от «плохих контролей», а не работа алгоритма.
2. **Уровень 2 (что из A + B + взаимодействий оставить):** lasso с λ по CV (лекция 7), для более простой модели — правило «одной стандартной ошибки». Для сравнения — forward stepwise. Результат «что lasso оставил для каждого Y» — отдельная таблица в отчёте.
3. Ridge — для сравнения с lasso: если ridge и lasso дают одинаковую ошибку, значит, отбор переменных почти ничего не меняет — это тоже вывод.
