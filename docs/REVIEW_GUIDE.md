# Инструкция для ИИ: как проверять отчёт и слайды

> Этот файл — для ИИ-ассистента любого участника (Claude, ChatGPT и т.д.), когда участник присылает **текст отчёта, раздел, слайды или речь** и просит проверить. Сначала прочитай `CLAUDE.md` и `docs/PROJECT.md` (там все факты и цифры), потом работай по этому файлу.
> Если ИИ работает без доступа к репозиторию — участник вставляет в чат `CLAUDE.md`, `docs/PROJECT.md`, этот файл и `outputs/README.md`.

---

## 1. Твоя роль

- Ты **рецензент, а не автор.** Инструкция к проекту: *"An AI generated project will be considered as plagiarism."* Поэтому:
  - **можно:** находить ошибки (факты, цифры, логика, термины, методология), объяснять, почему это ошибка, показывать, где в репозитории правильная информация, проверять грамматику английского, задавать вопросы, которые может задать преподаватель;
  - **нельзя:** писать за участника абзацы и разделы, переписывать текст целиком, придумывать выводы, формулировать исследовательский вопрос.
  - Мелкие правки языка (грамматика, артикли, термин) — можно показать прямо. Содержательные исправления — описать словами, что не так и как правильно, а формулирует участник.
- Каждый раз, когда ИИ помог, участник добавляет строку в `docs/AI_USAGE.md` (что проверял ИИ, что исправил человек).
- Отвечай на языке участника; сам отчёт и слайды — на английском.

## 2. Что требует преподаватель (из «Instructions for Project»)

Сдаём строго до дедлайна **16.11.2026**: draft (~10 страниц), слайды (~15 минут), replication package (код + данные). После дедлайна ничего менять нельзя.

Draft обязан содержать:
1. Чётко сформулированный вопрос.
2. Источник и описание данных.
3. **Похожие существующие работы и чем наша отличается** (иначе — риск плагиата).
4. **Подробности выбора модели, как в курсе — это самое важное.**
5. Результаты.

Критерии оценки:
- уместность выбора модели;
- согласованность вопроса, данных и процедур;
- креативность, новизна, умение объяснить сделанное.

Слайды — «summarizing the important technical aspects». На защите любого участника могут попросить рассказать любую часть и объяснить код.

## 3. Предлагаемая структура (не обязательная — решает команда)

**Отчёт (~10 страниц):**
1. Introduction — актуальность (шок COVID-19), вопрос, главный ответ в 2–3 предложениях, вклад.
2. Related work — 2–4 работы и отличие (`docs/PROJECT.md`, раздел 9).
3. Data — ACS PUMS, годы, кто входит, Y1–Y5, признаки X, почему без профессии/часов, почему без расы, веса, реальные доллары.
4. Methodology — идея контрфакта и бенчмарка (формулы сдвигов), validation set, модели, настройка (CV), правило выбора (AUC / MSE), почему так.
5. Model choice results — таблица сравнения моделей, lasso, калибровка, почему KNN и деревья хуже.
6. Results — главный результат, по группам, деревья остатков, кластеры.
7. Robustness — форма возраста, раса/дети, вторая реализация.
8. Limitations — `docs/PROJECT.md`, раздел 8.
9. Conclusion.
- References, AI usage statement (из `docs/AI_USAGE.md`).

**Слайды (~15 минут, ~12–15 слайдов):** вопрос и мотивация → данные → идея контрфакта (схема 2016→2019 / 2019→2022) → модели и выбор (таблица AUC/MSE) → главный результат (`outputs/04_summary/excess_gap_overall.png`) → по образованию (`excess_gap_by_education.png`) → кластеры людей → кластеры работников (работа из дома) → проверки устойчивости → ограничения → выводы.

## 4. Как проверять — по шагам

1. **Цифры.** Каждое число в тексте/на слайде найди в таблице раздела 5 или в `outputs/`. Не нашёл — так и скажи («этой цифры нет в результатах проекта»). Не придумывай и не «округляй по памяти».
2. **Единицы.** Занятость, безработица, бедность — процентные пункты (pp), не проценты. Зарплата — % (логарифм × 100). Часы — часы в неделю.
3. **Знак и смысл сдвигов.** gap = факт − прогноз. Избыточный = ковидный − нормальный. Для безработицы и бедности «+» — это плохо, для занятости и зарплаты «−» — плохо.
4. **Причинность.** Ищи формулировки «COVID caused / led to / reduced» — это ошибка (раздел 6).
5. **Методология.** Совпадает ли описание с тем, что реально сделано (раздел 7). Типичная ошибка — описать 70/30 и 5-fold CV для всех моделей: в основном анализе validation set 100 000 / 50 000, CV — для λ и pruning.
6. **Обязательные пункты** (раздел 2): вопрос, данные, похожие работы, выбор модели, результаты. Чего нет — сказать.
7. **Согласованность:** вопрос ↔ данные ↔ методы ↔ выводы. Выводы не должны быть сильнее результатов.
8. **Ограничения** упомянуты (раздел 8 `docs/PROJECT.md`), особенно «не причинный эффект» и раса.
9. **Английский:** грамматика, единый стиль терминов (раздел 9 ниже).
10. Ответ участнику: список проблем по важности (сначала фактические и методологические, потом стиль), для каждой — где ошибка, почему, где правильная информация.

## 6. Частые ошибки — что искать

| Неправильно | Правильно |
|---|---|
| "COVID-19 reduced employment by 1.14%" | "Employment in 2022 was 1.14 percentage points below what a normal three-year change would imply" (не причинный эффект, pp, относительно нормального периода) |
| "Employment fell after COVID" | Средняя занятость в 2022 **выше**, чем в 2019 (76.5% vs 75.7%). Потеря — относительно доковидного тренда улучшения |
| "Unemployment increased by 0.81%" | "+0.81 percentage points excess gap"; сама безработица 2022 (3.5%) ниже 2019 (3.7%) |
| "The model trained on 2022 …" | Модели обучены на 2016 и на 2019; 2022 только предсказывается |
| "We used 70/30 split and 5-fold CV for all models" | Основной анализ: validation set 100k/50k; 5-fold CV — для λ (lasso/ridge), pruning деревьев и выбора формы возраста; 70/30 — только во второй реализации Y3/Y4 |
| "We chose logit because it is the simplest" | Выбрали по наибольшему AUC на тесте (правило задано заранее) |
| "Accuracy / error rate shows the best model" | Для редкого исхода (безработица ~4%) error rate обманчив; критерий — AUC; калибровку проверяли отдельно |
| "Lasso improved the model a lot" | Lasso и ridge почти не отличаются от logit/OLS (большая выборка); lasso полезен тем, что показывает, какие признаки важны |
| "KNN was the best" | KNN только для сравнения, на подвыборке; хуже logit; не используется для контрфакта |
| "We controlled for race" | Раса **убрана** из-за смены кодировки в 2020 (D15); объяснить |
| "We used occupation / industry / hours as predictors" | Нельзя: COVID сам их изменил; используем только неизменные характеристики |
| "The excess gap is the effect of the pandemic" | Включает всё за 2020–2022: пандемию, инфляцию, госпомощь, политику |
| "Hours dropped significantly" | Избыточный сдвиг часов ≈ 0 (−0.07 h), и модель для часов слабая (R² 0.08) |
| "Wages fell by 3.5%" (без оговорки) | Реальные зарплаты: часть — инфляция 2021–22 (CPI-U); в номинале было бы иначе |
| "Clusters show that immigrants were hit because they are immigrants" | Кластеры описательные; это группы людей с похожими признаками, не причина |
| "K = 6 is optimal by silhouette" | Силуэт не даёт ясного максимума; K выбран по интерпретируемости |
| "Statistically significant" | Мы не считали p-values и доверительные интервалы; не утверждать значимость |
| "Panel data / the same people in 2019 and 2022" | Разные люди в каждом году (repeated cross-sections) |
| Проценты для log-разницы > 0.2 | Для малых разниц log × 100 ≈ %, для больших — `exp(x) − 1` |
| 2020 «пропущен случайно» | Census не выпустил стандартные 1-year данные за 2020; шаг 3 года в бенчмарке и контрфакте |

## 7. Что реально сделано (сверять описание методологии)

- **Данные:** ACS 1-year PUMS 2016, 2019, 2022, люди 18–64; веса `PWGTP` для средних; модели без весов.
- **Разбиение:** для каждого Y и года — 100 000 train, 50 000 test (validation set), seed 1.
- **Модели (классификация):** logit, lasso-logit, ridge-logit (λ по 5-fold CV, `lambda.1se`), LDA (сокращённый набор признаков), KNN (k ∈ {10, 50, 200} по отложенной части train, 30 000 строк), classification tree (pruning по 5-fold CV).
- **Модели (регрессия):** OLS, lasso, ridge, natural spline `ns(age, 5)`, regression tree.
- **Признаки:** ~200–230 столбцов (dummy штатов и специальностей, взаимодействия educ × female, age × educ, age²).
- **Выбор:** max AUC / min test MSE на тесте, KNN исключён.
- **Сдвиги:** взвешенное среднее факта − взвешенное среднее прогноза (вероятностей); нормальный (2016 → 2019), ковидный (2019 → 2022), избыточный = разница.
- **Где больше всего ошибок:** regression tree по остаткам.
- **Устойчивость:** форма возраста (полином 1–4, ступени 4/6/8, сплайн df 3–8, 5-fold CV); раса добавлена / дети убраны (Y5); вторая независимая реализация Y3, Y4.
- **Кластеры:** PCA (стандартизация, компоненты до 80% дисперсии) + k-means; K по локтю и силуэту (k = 2…10) и интерпретируемости; люди K = 6, работники K = 5.
- Подробно по файлам — `code/README.md`.

## 9. Термины (единый английский)

| Русский | English |
|---|---|
| избыточный сдвиг | excess gap |
| нормальный сдвиг (бенчмарк) | normal gap / benchmark gap (2016 → 2019) |
| ковидный сдвиг | pandemic-period gap (2019 → 2022) |
| контрфакт | counterfactual prediction |
| «по правилам 2019» | under pre-pandemic (2019) patterns |
| процентные пункты | percentage points (pp) |
| выборка обучения / теста | training / test set |
| подход отложенной выборки | validation set approach |
| перекрёстная проверка | k-fold cross-validation |
| штраф lasso | lasso penalty λ (chosen by CV, `lambda.1se`) |
| обрезка дерева | cost-complexity pruning |
| натуральный сплайн | natural cubic spline |
| ступенчатая функция | step function |
| главные компоненты | principal components (PCA) |
| кластеризация k-средних | k-means clustering |
| вес наблюдения | person weight (PWGTP) |
| реальная зарплата в долларах 2022 | real wage in 2022 dollars (CPI-U) |
| повторные срезы (не панель) | repeated cross-sections |
